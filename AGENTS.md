# Overview

This is a project to port an old game called XQuest 2 to Rust/WASM and have it run on the web. The original source code in Pascal is in the `xquest2_source` directory.

# Prose style

Do not use creative or weird verbs like 'carries' or 'owns'.

# Code style

Remember to include blank lines within Rust functions where appropriate to make them more readable.

When there is a choice between an easy low risk but hacky solution, and a higher risk big change that leads to a more elegant and correct solution, choose the latter.

# Commit style

Commit regular small changes. Do not wrap lines. Do not include co-authored-by.

Commit directly to `master`.
